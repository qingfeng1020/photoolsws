# 最省事上传方案：网页拖拽上传（无需任何命令行）

> 我已经帮你把改好的代码打包成了一个 zip 文件：`photools-ios15-trollstore-src.zip`（4.3MB）。
> 下面教你用**纯网页点击**的方式，把它上传到 GitHub 并触发编译。
> **全程不用敲任何命令，不用装 Git，不用 Mac。**

---

## 你需要准备的

- 一个 GitHub 账号（免费，github.com 注册）
- 我给你的 `photools-ios15-trollstore-src.zip` 文件
- 一台能解压 zip 的电脑（你的 Windows 就行）

---

## 第 1 步：解压 zip

在 Windows 上右键 `photools-ios15-trollstore-src.zip` → **全部解压**。

解压后你会得到一个文件夹：
```
photools/
├── .github/
│   └── workflows/
│       └── build-ios.yml          ← 自动编译脚本（已帮你写好）
├── apps/
│   └── ios/
│       └── PhotoolsMobile/        ← 改好的 iOS 工程
└── .gitignore
```

---

## 第 2 步：在 GitHub 上创建一个空仓库（不是 fork）

> ⚠️ 注意：这里**不是 fork**，而是「新建一个属于你自己的空仓库」。因为 fork 出来的仓库已经有原版文件，网页上传覆盖会很麻烦。新建空仓库后，直接把解压的文件夹拖进去最省事。

1. 登录 github.com
2. 点右上角 **+** 号 → **New repository**
3. 填写：
   - **Repository name**：`photools`（或任意名字，如 `nikongps`）
   - **Description**：随意，可不填
   - **Public / Private**：选 **Public**（公共仓库，编译免费不限时）
   - ⚠️ **不要勾选**「Add a README file」（保持空仓库）
   - ⚠️ **不要勾选**「.gitignore」「license」模板
4. 点绿色 **Create repository** 按钮

---

## 第 3 步：拖拽上传整个文件夹（关键！）

1. 进入你刚创建的空仓库页面，会看到「Quick setup」提示；
2. 找到 **「uploading an existing file」** 链接（蓝色文字），点它；
3. 进入上传页面后，**把解压出来的整个 `photools` 文件夹，直接拖进页面中央的虚线框**；
   - GitHub 会识别出文件夹结构，自动递归上传所有子文件；
   - 你会看到文件列表里包含 `.github/workflows/build-ios.yml`、`apps/ios/...` 等；
4. 稍等上传完成，页面下方会显示文件列表；
5. 在「Commit changes」输入框里写一句说明（如 `首次上传 NikonGPS iOS15 改造版`）；
6. 点绿色 **Commit changes** 按钮。

> ✅ 上传成功后，你的仓库里就有了完整的项目 + 编译脚本。

---

## 第 4 步：触发编译

1. 在仓库页面点顶部 **Actions** 标签；
2. 如果提示「I understand my workflows, go ahead and enable them」，点绿色按钮启用；
3. 左侧找到 **「Build NikonGPS IPA (iOS 15 / TrollStore)」**；
4. 右侧点 **Run workflow** → 绿色 **Run workflow** 确认；
5. 出现黄色转圈圆点 = 编译开始。

---

## 第 5 步：下载 ipa

1. 等 **5~8 分钟**（云端 macOS 编译 + 打包）；
2. 黄色圆点变**绿色对勾** = 成功；
3. 点进这个任务，滚到页面底部 **Artifacts** 区；
4. 下载 `NikonGPS-iOS15.0-ipa`；
5. 解压即得 `NikonGPS-iOS15.0.ipa`。

> 若变**红色叉叉**，把报错截图发我，我帮你修。

---

## 第 6 步：装到 iPhone 6s

1. 把 `.ipa` 传到 iPhone（AirDrop / 微信 / 网盘 / 数据线）；
2. 「文件」App 里找到它 → 点分享 → 选 **TrollStore** → 安装；
3. 桌面出现 **NikonGPS**，即可使用。

## 常见问题

**Q：拖拽上传时提示文件太多/太大？**
A：包只有 4.3MB、69 个文件，远低于 GitHub 上限（单文件 100MB，一次可传成百上千个），不会有问题。

**Q：我看不到「uploading an existing file」链接？**
A：空仓库首页有「Quick setup」区块，里面有蓝色链接「or create a new repository...」附近能找到「uploading an existing file」。或者直接浏览器访问：`https://github.com/你的用户名/仓库名/upload`

**Q：隐藏的 `.github` 文件夹拖不进去？**
A：Windows 资源管理器默认隐藏以 `.` 开头的文件夹。请先在「查看」里勾选「隐藏的项目」，让 `.github` 显示出来，再整体拖拽。或者：解压后直接选中 `photools` 文件夹整体拖进浏览器，GitHub 会自动包含其中的隐藏文件夹。

**Q：为什么是新建仓库而不是 fork？**
A：fork 会带上原版全部文件，网页上传"覆盖已有文件"很麻烦（要逐个点）。新建空仓库 + 拖拽上传 = 一次搞定，最省事。

**Q：这样没有原作者的 git 历史了，有关系吗？**
A：没关系。你只是要编译出 ipa 用，不需要 git 历史。原项目是 MIT 开源协议，你保留 LICENSE 文件即可（我已打包进去）。
